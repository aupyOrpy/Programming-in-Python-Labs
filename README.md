## Run the notebooks

Open any notebook on GitHub to read it with its output, or run it yourself:

```bash
pip install notebook
jupyter notebook
```

You can also open a notebook in [Google Colab](https://colab.research.google.com/) with **File > Open notebook > GitHub** and paste this repository's URL.
